# Security

If you find a security issue that could expose user files, weaken proof verification, bypass package checks, or abuse the timestamp relay, please report it privately.

Use the ProofStamp contact form:

https://proofstamp.org/contact-us/

Please include the affected build or commit when known, a short description of the issue, and steps to reproduce it. Do not include sensitive user files unless they are necessary to demonstrate the problem.

Please do not open a public GitHub issue for an unpatched security vulnerability.
